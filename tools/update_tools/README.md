# LN_config 使用说明

板子快速运维入口，双击即弹出，脚本搞定 4 件事：**部署 / 查版本 / 拉日志 / 拉烟**。

## 快速上手

启动后菜单:

```
[D]eploy (default)  /  [Q]uery version  /  [G]rab latest bag  /  [T]rigger smoke
```

| 你想做什么 | 操作 | 备注 |
|---|---|---|
| **软更新代码到板子** | 双击 `LN_config.bat` → 输入 IP → 默认 `[D]eploy` | 当前目录放 `tzs_ws_bundle_*.tar.gz`(自动找最新) |
| **看板子跑的版本** | 双击 → 输入 IP → 选 `Q` | 返回的版本号为x.x.x，具体版本号与更新见软件版本说明 |
| **拉最近一次飞行的日志** | 双击 → 输入 IP → 选 `G` | 拉回 bat 所在目录,文件名 `multi_uav_flight_<N>_<M>.bag` |
| **手动触发拉烟** | 双击 → 输入 IP → 选 `T` → 输 `y` 确认 | 直接发送拉烟指令， |

> 默认 IP `192.168.1.151`,直接回车即可。

## 准备事项

1. Windows 自带 OpenSSH 客户端(Win10 1809+),`ssh` / `scp` 已可用（正常windows均具备）
2. 接入网络，可以ping通目标板

## 注意事项

- **第一次提示输 SSH 密码**,脚本后续可能依旧会再问ssh密码，这是Windows上OpenSSH的问题，可以采用复制粘贴的方式快速填写
- **`G` 拉日志会先温柔停板子 rosbag**(SIGINT,等 `.active` 收尾成 `.bag`,最多等 30s),**不会删任何文件**
- **版本号为0.0.1及以下的软件不支持手动触发拉烟`T` 功能**
